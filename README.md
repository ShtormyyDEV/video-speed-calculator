# Video Speed Calculator ⏱️

Простой и удобный калькулятор на Python для быстрого расчёта времени просмотра видео, уроков или аудиокниг на ускорении (`1.25x`, `1.5x`, `2x`).

## 🚀 Что уже работает (v1.0)
* Перевод исходного времени (часы, минуты, секунды) в единый формат.
* Выбор популярной скорости воспроизведения в цикле.
* Защита от ввода некорректной скорости.

# Video Speed Calculator (EN) ⏱️

A simple and handy Python calculator to quickly calculate watch time for videos, lessons, or audiobooks at different playback speeds (`1.25x`, `1.5x`, `2x`).

## 🚀 Current Features (v1.0)
* Converts initial time (hours, minutes, seconds) into a unified format.
* Interactive loop for selecting popular playback speeds.
* Basic input validation for incorrect speed values.

## 🛠 Roadmap
* [ ] **v1.1:** Exact time calculation down to the second.
* [ ] **v2.0:** Graphical user interface (window with input fields and buttons using Tkinter).
* [ ] **v2.1:** Protection against clicking buttons when input fields are empty.
* [ ] **v2.2:** Custom background color and dark theme support.
* [ ] **v3.0:** Packaging into a standalone `.exe` file for Windows.
